## route-map-2026-04.pdf（首都圏路線図 2026年4月1日現在）

首都圏エリアの路線図。2026年4月1日現在。

**使えること**
- 首都圏に存在する駅名の網羅リスト（テキスト抽出できる）
- 路線名の正式表記
- どの路線がどのエリアを走っているか

**使えないこと**
- **駅の並び順は取れない。** テキスト抽出すると駅名がバラバラの羅列になる。
  順序を判断する根拠には使えない。

**したがって使いかたは1つ。**
「AIが並べた駅名が、そもそも実在する駅かどうか」の照合に使う。
抽出したテキストに無い駅名を書いていたら、その時点で誤り。

## jr-numbering-symbols.png（JRグループ ナンバリング記号一覧）

JR各社の駅ナンバリング記号一覧（2018年8月時点）。

**フェーズ2（ナンバリング追加）で使う。**
フェーズ1のあいだは参照不要。

**注意：2018年時点の情報。** その後に追加・変更された記号がある可能性があるため、
これだけを根拠にせず、他の資料と照合すること。
高輪ゲートウェイ駅の扱いなど、この画像より後に変わったものがある。
