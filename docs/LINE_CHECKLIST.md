## 要確認メモ（人に見てほしい点）

### 1. 麹町 の字体が資料間で違う（有楽町線 Y15）

- 東京メトロ公式：**麹**町（U+9EB9・新字体）← データはこちらを採用
- 路線図PDF：**麴**町（U+9EB4・旧字体）

`refs/map-station-names.txt` との照合で、216駅中これだけがヒットしない。
別字なのでUnicode正規化では吸収されない。どちらを正とするか決めてほしい。

### 2. 市ケ谷 と 市ヶ谷 も事業者で違う（有楽町線 Y14／南北線 N09／都営新宿線 S04）

- JR東日本・東京メトロ：市**ケ**谷（大きいケ）← データはこちらを採用
- 都営地下鉄：市**ヶ**谷（小さいヶ）

物理的に同じ駅なので `ichigaya` の1エントリに統合してある。
路線図PDFも「市ケ谷」なので照合は通る。
UIで都営の駅として出すときに表記を変えるかどうかは未決。

### 3. 駅の並び順の起点

全路線とも**駅ナンバリングの01側を先頭**にした。
そのため路線図や時刻表の「上り／下り」の向きとは一致しない場合がある。

- 銀座線：渋谷(G01) → 浅草(G19)　※Wikipediaの「起点」は浅草
- 丸ノ内線：荻窪(M01) → 池袋(M25)　※Wikipediaの「起点」は池袋
- 千代田線：代々木上原(C01) → 北綾瀬(C20)　※Wikipediaの「起点」は綾瀬
- 都営浅草線：西馬込(A01) → 押上(A20)　※正式な起点は押上

### 4. 大江戸線の環状部が一本道として表現されている

大江戸線は「6の字」形で、都庁前(E28)を境に環状部と放射部に分かれる。
`stations[]` は一本道の配列なので、E01→E38 の順に並べてある。

```
新宿西口(E01) … 新宿(E27) → 都庁前(E28) → 西新宿五丁目(E29) … 光が丘(E38)
```

隣り合う駅同士は実際に隣接しているので配列としては正しいが、
**環状部を閉じる「都庁前(E28)〜新宿西口(E01)」の接続だけが表現できていない。**
UIで環状に見せたい場合は、この1本を別途持つ必要がある。

### 5. 丸ノ内線分岐線を別ファイルにした

`stations[]` は一本道の配列なので分岐が表現できない。
中野坂上〜方南町を別ファイルにし、**中野坂上を両方に入れて**繋げてある。

分岐線側の駅番号は東京メトロ公式の **小文字 m**（m03/m04/m05）を採用。
路線図の凡例では **Mb** と書かれており表記が違う。UI でどちらを出すか要決定。

なお千代田線の綾瀬〜北綾瀬は C19→C20 と連番で一本道なので、本線ファイルに含めてある。

### 9. 路線カラーの出典を marorika のページに切り替えた

利用者の指示により、全14路線のカラーコードを
<https://www.marorika.com/entry/tokyo-metro-line-color-code> の掲載値に統一した。

**ただし浅草線と新宿線は、路線図凡例から実測した色と系統がずれている。**

| 路線 | 採用値（marorika） | 事業者公表値 | 凡例JPGの実測値 | 色相差 |

| 東京メトロ9路線 | — | — | — | 2〜15°（実用上の差なし） |

浅草線は本来「ローズ」（ピンク系）だが採用値は赤橙、
新宿線は本来「リーフ」（緑）だが採用値は黄緑〜オリーブになる。
路線図と並べて見ると違って見えるので、気になる場合は下記で戻せる。

生成スクリプトの `USE_MARORIKA = False` にすると事業者公表値に戻る。
`colorName`（オレンジ／ローズ など）は事業者の公表名のままにしてある。

### 「ケ／ヶ」の扱い

事業者の正式表記（多くは小さいヶ）を優先し、路線図PDFの表記（大きいケで統一される
傾向）とは食い違うことがある。`node tools/audit.mjs` の「字体ゆれ」検査で
同じ駅の二重登録がないか確認できる。現状の検出は次の1件のみで、これは実在する別駅。

- 霞ケ関（東京メトロ・大きいケ）／霞ヶ関（東武東上線・埼玉県川越市・小さいヶ）

### デバッグで見つけて直したアプリの不具合

- 駅詳細の「つぎのえき」に `undefined` が出ていた（駅番号を持たない路線で発生）
- 実在しない路線記号「JR」を仮置きしていた（駅番号を持たない34路線）
- 半角カタカナで検索できなかった
- 座標検査が同名の別駅の座標を拾って誤検知していた

詳しい経緯は [docs/DECISIONS.md](DECISIONS.md) を参照。
